# controle-gado
Sistema simples para controle de matrizes, nascimentos e manejos de terneiros da Agropecuária Paineira.

## V1
- Matrizes
- Nascimentos vinculados à mãe
- Manejos
- Relatórios
- Backup em JSON

Nesta primeira versão os dados ficam no navegador (localStorage). A próxima etapa é conectar Firebase/Firestore para sincronização entre celular e computador.
